# Политика конфиденциальности

Редакция от 20.10.2026

Shifr SMS обрабатывает только те данные, без которых сервис не может работать: данные Telegram-профиля или аккаунта на сайте, историю активаций, операции по балансу и обращения в поддержку. Номер телефона, контакты и переписки Пользователя в Telegram бот не получает. Платёжные данные вводятся на странице платёжного партнёра и Сервису не передаются.

## 1. Общие положения

1.1. Настоящая Политика конфиденциальности (далее — «Политика») описывает, какие данные Пользователя обрабатывает сервис активации SMS Shifr SMS, доступный в Telegram по адресу https://t.me/shifrSMSbot и на сайте https://shifrsms.shop (далее — «Сервис»), для чего они используются и как защищаются.

1.2. Используя Сервис, Пользователь подтверждает своё согласие с условиями Политики. Если Пользователь не согласен с условиями, он обязан прекратить использование Сервиса.

## 2. Какие данные обрабатываются

2.1. Данные Telegram-профиля, которые бот получает автоматически: идентификатор (ID), имя и имя пользователя (@username).

2.1.1. Для аккаунта на сайте — логин и пароль (пароль хранится только в виде необратимого хеша), выбранный язык, а также ключ API (тоже только в виде хеша). Браузер хранит cookie сессии (для входа), выбранного языка и — до 90 дней — кода приглашения, если Пользователь пришёл на сайт по ссылке-приглашению. Сайт не использует рекламные и аналитические cookie и счётчики. При входе через Telegram (а также при привязке Telegram и сбросе пароля) бот показывает тип браузера, страну, определённую по адресу запроса, и время запроса, чтобы Пользователь мог убедиться, что запрос сделал он; страна не сохраняется. При привязке Telegram данные аккаунта сайта и бота объединяются.

2.2. Данные об использовании Сервиса:
- баланс и операции по нему (пополнения, оплаты активаций, возвраты, вознаграждения за приглашения);
- активации: сервис, страна, выданный номер, стоимость, время запуска и окончания, статус и текст поступивших SMS;
- счета на пополнение: сумма, способ оплаты, статус и номер операции у платёжного партнёра или Telegram;
- кто пригласил Пользователя (другой пользователь или канал-партнёр; после объединения аккаунтов — до двух пригласивших) и метка рекламной ссылки, по которой Пользователь впервые открыл бота.

2.3. Обращения в службу поддержки: сообщения и файлы, которые Пользователь отправляет в поддержку через бота или сайт. Текст переписки хранится, чтобы Пользователь видел историю обращений на сайте.

2.4. Сервис не запрашивает паспортные данные, документы, фотографии, номер телефона Пользователя и реквизиты банковских карт. Бот не получает IP-адрес и сведения об устройстве Пользователя. Сайт использует IP-адрес только для защиты от подбора паролей и массовых регистраций и не сохраняет его в базе данных.

2.5. Сервис не получает и не хранит данные учётных записей, которые Пользователь создаёт с помощью активаций (логины, пароли и т. п.).

2.6. Для партнёров — владельцев Telegram-каналов дополнительно обрабатываются: название, ссылка, описание и число подписчиков канала (для проверки при подключении), логин и хеш пароля кабинета, секрет аутентификатора и хеши резервных кодов, сохранённые адреса USDT, история начислений и выводов. Переводы в сети TRON публичны: адрес получателя и сумма видны всем в обозревателе сети.

## 3. Цели обработки

3.1. Данные используются для:
- оказания услуги: запуска активаций, доставки кодов из SMS, отображения истории в разделе «📋 Мои заказы» в боте и «Заказы» на сайте;
- учёта баланса и платежей;
- ответов на обращения в службу поддержки;
- уведомлений о поступлении SMS, зачислении платежей и вознаграждений и информационных сообщений о работе Сервиса;
- расчёта вознаграждения партнёрам Сервиса и пригласившим пользователям;
- анализа и улучшения работы Сервиса (например, статистики успешных активаций по странам и поставщикам, эффективности рекламных ссылок);
- предотвращения злоупотреблений и нарушений Пользовательского соглашения.

## 4. Передача данных третьим лицам

4.1. Платёжному партнёру передаются сумма и номер счёта на пополнение — только для проведения оплаты. Данные, которые Пользователь вводит на странице оплаты, обрабатывает платёжный партнёр по своим правилам. Оплату звёздами проводит Telegram.

4.2. Партнёрам-поставщикам номеров данные Пользователя не передаются: для выдачи номера им сообщаются только сервис и страна активации.

4.3. Партнёры Сервиса (владельцы Telegram-каналов) видят только начисления своего вознаграждения по активациям привлечённых пользователей — без имени, идентификатора и номеров этих пользователей. Пригласивший пользователь видит только число приглашённых и сумму вознаграждения.

4.4. Помимо этого, данные передаются третьим лицам только в случаях, предусмотренных законодательством.

4.5. Сообщения между Пользователем и ботом передаются через Telegram в соответствии с его правилами.

4.6. Сайт работает через сеть Cloudflare, которая защищает его от атак и передаёт запросы браузера на сервер Сервиса. Изображения флагов стран сайт загружает с сервиса flagcdn.com. При этом Cloudflare и flagcdn.com получают стандартные сведения запроса (IP-адрес, тип браузера) и обрабатывают их по своим правилам.

## 5. Хранение и защита данных

5.1. Данные хранятся на сервере Сервиса. Доступ к ним есть только у Администрации и сотрудников службы поддержки — в объёме, необходимом для их работы.

5.2. Данные хранятся, пока Пользователь пользуется Сервисом, а данные о платежах — также в течение срока, необходимого для учёта расчётов.

5.3. Администрация принимает разумные технические и организационные меры для защиты данных (шифрованное соединение, хранение паролей и ключей только в виде хешей, ограничение попыток входа), но не может гарантировать абсолютную безопасность передачи информации через интернет.

## 6. Права Пользователя

6.1. Пользователь может через службу поддержки (в боте: «ℹ️ Информация» → «💬 Поддержка», на сайте: раздел «Поддержка») узнать, какие его данные хранятся, и запросить их удаление.

6.2. После удаления данных история активаций и баланс Пользователя становятся недоступны. Данные о платежах могут храниться дольше, если это необходимо для учёта расчётов.

6.3. Пользователь может в любой момент прекратить получать сообщения от бота, заблокировав его в Telegram. Пользователю сайта без привязанного Telegram бот сообщений не отправляет.

## 7. Изменения Политики

7.1. Администрация вправе изменять Политику. Актуальная редакция публикуется по ссылке, доступной в боте (раздел «ℹ️ Информация») и внизу каждой страницы сайта.

7.2. Продолжение использования Сервиса после изменения Политики означает согласие Пользователя с новой редакцией.
