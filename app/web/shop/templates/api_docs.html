{{ 'Price and country selection' if en else 'Выбор цены и страны' }}

    {% if en %}
  • Each country has several price levels: as a rule, the more expensive, the more reliable.
  • Without max_price (maxPrice) — the cheapest level is bought. With it — the most expensive (most reliable) level not above it.
  • Without a country — Auto mode: the most reliable activation in the price range across all countries.
  • If no SMS arrives, the money returns to the balance automatically (on expiry, cancel or replacement).
    • {% else %}
  • У каждой страны несколько уровней цены: как правило, чем дороже, тем надёжнее.
  • Без max_price (maxPrice) покупается самый дешёвый уровень. С ним — самый дорогой (надёжный) уровень не дороже указанной цены.
  • Без страны — режим «Авто»: самая надёжная активация в ценовой категории среди всех стран.
  • Если SMS не придёт, деньги вернутся на баланс сами (по истечении, при отмене или замене номера).
